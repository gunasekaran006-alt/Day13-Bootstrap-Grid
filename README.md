
This repository contains a simple, clean example of the **Bootstrap 5 Grid System**. It demonstrates how to create a responsive layout that adapts to mobile, tablet, and desktop screens using utility classes.

## 🚀 Features
- **Responsive Design**: Uses breakpoints (`col-12`, `col-md-4`, `col-lg-3`) to adjust layout based on screen width.
- **Bootstrap CDN**: Integrated via [Bootstrap's Official CDN](https://getbootstrap.com) for quick loading.
- **MERN Stack Themed**: Displays MongoDB, ExpressJS, ReactJS, and NodeJS in a grid format.
- **Gutter Support**: Uses `g-3` for consistent spacing between columns.

## 📱 Breakpoint Logic in this Project
- **Mobile (<768px)**: 1 column per row (Stacked).
- **Tablet (≥768px)**: 3 columns per row.
- **Desktop (≥992px)**: 4 columns per row.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Bootstrap 5.3.x Framework)
